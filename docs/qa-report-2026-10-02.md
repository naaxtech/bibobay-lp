Observations (no failing spec; for the controller's judgement):

- `/thank-you` says "You can ask to be removed at any time by replying to any BIBO Bay email." No email is sent while email is unconfigured. It does not claim delivery (asserted), but it presumes outgoing mail exists. Worth a wording check against section 3 ruling 3 and section 17 criterion 5 before launch.
- Public pages answer `Cache-Control: private, no-cache, no-store` (dynamic rendering for the per-request CSP nonce), and unhashed images under `/brand/art/` answer `public, max-age=0`, so a repeat visit revalidates every image. Not covered by an acceptance criterion; Lighthouse in the preview pass should measure its effect.
- On this server every public page is `noindex` and the sitemap is empty, which is correct without a verified production URL (section 14). The one spec that asserts this is skipped for non-loopback base URLs.
